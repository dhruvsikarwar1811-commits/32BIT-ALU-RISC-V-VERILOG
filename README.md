# 32-bit ALU for RISC-V Architecture

A 32-bit Arithmetic Logic Unit (ALU) implemented in Verilog HDL,
supporting core RISC-V RV32I operations.

## Operations Supported
| ALU Op | Operation |
|--------|-----------|
| 0000   | Addition  |
| 0001   | Subtraction |
| 0010   | AND |
| 0011   | OR |
| 0100   | XOR |
| 0101   | Shift Left |
| 0110   | Shift Right |
| 0111   | SLT (Set Less Than) |

## Tools Used
- Verilog HDL
- Icarus Verilog 12.0
- EDA Playground
